# C# Studies

This repository is dedicated to my personal learning journey with C#.  
It contains examples, notes, and small projects covering a variety of topics such as:

- Syntax and fundamentals
- OOP (Object-Oriented Programming)
- LINQ
- Asynchronous programming
- .NET features
- Design patterns
- And more...

Feel free to explore and suggest improvements!

---

## 📁 Directory Overview

### [`00-Getting-Started`](./00-Getting-Started)
> Initial setup, tools, and the classic "Hello World".  
Start here if you're new to C# or setting up your development environment.

### [`01-Basics`](./01-Basics)
> Covers variables, data types, operators, control structures, and functions.  
A foundation for understanding the C# language.

### [`02-OOP`](./02-OOP)
> Deep dive into Object-Oriented Programming: classes, inheritance, encapsulation, polymorphism, and interfaces.  
The building blocks of robust, scalable code.

### [`03-Advanced-CSharp`](./03-Advanced-CSharp)
> Learn more powerful features of C#, such as delegates, events, generics, collections, exception handling, and async/await.

### [`04-DotNet`](./04-DotNet)
> Explore practical applications using .NET: console apps, desktop interfaces, ASP.NET Core (Web API & Razor Pages), and Entity Framework.

### [`05-Testing-And-Tools`](./05-Testing-And-Tools)
> Fundamentals of testing in C#: unit tests, xUnit, debugging techniques, and profiling tools.

### [`06-Design-Patterns`](./06-Design-Patterns)
> Common design patterns implemented in C# like Singleton, Factory, Repository, and Dependency Injection.  
Useful for writing clean, maintainable code.

### [`07-Projects`](./07-Projects)
> Mini-projects that apply the concepts learned throughout this repository.  
Includes console apps, web APIs, and CRUD examples using EF Core.
